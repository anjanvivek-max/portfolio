# Portfolio assets

Drop your real files here, then point to them from the data files in `src/data/`.

- `projects/`      project screenshots, e.g. `projects/ai-sql-assistant-1.png`
- `certificates/`  certificate images, e.g. `certificates/oci-ai-foundations.png`

Paths in the data files are relative to this folder's parent, for example
`assets/projects/ai-sql-assistant-1.png`.
